## 🛡️ About ChainSiren
ChainSiren coordinates critical halts, consensus splits, and zero-day patches across distributed validator fleets. We provide institutional-grade alerting and incident acknowledgment, cryptographically sealed with **EIP-712 non-repudiation**.

Our architecture is proprietary by design to guarantee the absolute security and resilience of the alerting infrastructure when mainnets face catastrophic events.

## 🔌 Zero-Infra Integration
ChainSiren is a fully managed SaaS. There is **no API to integrate, no microservices to host, and no infrastructure to maintain** on the validator's end. 

Alerts are pushed natively and securely to the tools your DevOps and SRE teams already use daily:
- **PagerDuty** (P1 Escalations)
- **Linear** (Automated Issue Tracking)
- **Discord** (War Room Webhooks)
- **Telegram** (Direct SRE Pings)
- **Slack** (Team Coordination)

## 🔐 Key Architectural Guarantees
- **EIP-712 Validation:** Every validator onboarding and incident acknowledgment requires a cryptographic signature to bind the operator's identity.
- **Severity-Based Routing:** Automated escalation filters (Green, Orange, Red, Black tiers) ensure teams are only woken up for critical consensus divergences, ignoring routine advisories.
- **Out-of-Band Coordination:** When a network goes down, ChainSiren remains up, providing a neutral layer for validator fleets to coordinate patches without relying on the compromised chain.
